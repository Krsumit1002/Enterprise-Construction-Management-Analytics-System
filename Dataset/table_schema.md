# Dataset & Table Schema

The project uses a construction management dataset stored in Google BigQuery.

## Tables

| Table | Purpose |
|---|---|
| `clients` | Client information |
| `employees` | Employee information |
| `invoices` | Invoice records |
| `materials` | Construction material information |
| `payments` | Payment transactions |
| `projects` | Construction project information |
| `purchases` | Procurement transactions |
| `vendors` | Vendor information |

## Data Warehouse

The dataset was stored and analyzed using Google BigQuery.

**Dataset:** `enterprise_construction`

**Platform:** Google BigQuery
